Five lines to a styled, sortable, filterable table

import { DataTable, useFrontendData } from "@adapttable/mantine";

function People({ rows }) {
  const source = useFrontendData({ data: rows, columns });
  return <DataTable source={source} columns={columns} rowKey={(r) => r.id} />;
}

Need full control? useDataTable from @adapttable/core gives you headless prop-getters and zero opinions.

Frequently asked questions

What is the best headless React data table that works with my UI kit?

AdaptTable is a headless React data table whose single core engine powers ready, batteries-included adapters for Mantine, MUI, Chakra, Ant Design, and Tailwind/shadcn. You get TanStack-Table-style headless freedom without building the UI yourself for your specific design system.

Is AdaptTable a free alternative to MUI X DataGrid or ag-Grid?

Yes. AdaptTable is MIT-licensed and fully free, including server-side data, infinite scroll, filtering, and selection. MUI X DataGrid and ag-Grid are open-core: their advanced server-side data and infinite-loading capabilities sit behind paid Pro/Premium or Enterprise tiers. The MUI adapter gives a DataGrid-style experience at no cost.

Does AdaptTable support right-to-left (RTL) and Arabic?

Yes — RTL is first-class. Column alignment uses logical CSS so it flips automatically under dir="rtl", and the i18n package ships 10 locales including Arabic and Hebrew with direction helpers.

Can I use the same table for client-side and server-side data?

Yes. One TableSource contract backs both useFrontendData (in-memory) and useBackendData (server-paginated via a useInfiniteQuery hook). The <DataTable> component doesn't change between them.

Does AdaptTable have seamless dark mode and animations?

Dark mode is inherited from your UI kit's theme and is seamless. Entrance animation is opt-in and dependency-free (Web Animations API); you can bring your own GSAP or Framer Motion via the data-stagger hooks, or run with no animation at all.
