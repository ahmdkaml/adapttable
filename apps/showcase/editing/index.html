AdaptTable demo — inline cell editing

Edit in place, with the editor each kit would use natively: a text input, a number field, a select, a date picker. Editing composes with everything else rather than replacing it — an edited row stays selected, stays filtered, and stays where sorting put it until the value actually changes.

What you can drive here

  • Click or keyboard into a cell, commit with Enter, abandon with Escape.
  • Per-column editors and validation, with the invalid state rendered by the kit's own field components.
  • Editing inside grouped rows, including rows off the current page.
  • Async commits, so a save can fail and roll the cell back without losing the rest of the edit session.
