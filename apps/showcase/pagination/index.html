React table pagination and infinite scroll

A classic pager and infinite scroll are the same query asked for in two ways, so AdaptTable treats them as one prop rather than two tables. Page number, page size and the loaded window all live in the URL, which means a link reopens the view someone was actually looking at instead of resetting them to the first page.

What you can drive here

  • Switch between a pager and infinite scroll and watch the same rows arrive a different way.
  • Change the page size, move between pages, and see both reflected in the address bar.
  • In infinite mode, scroll to extend one growing window rather than replacing the rows on screen.
  • Switch UI kit — the pager, its size control and the load indicator are that kit's own components.
