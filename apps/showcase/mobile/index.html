AdaptTable demo — automatic mobile card layout

Below a breakpoint the same table stops being a table. Rows become cards, the pager becomes infinite scroll, and every other behaviour carries over untouched: the same filters, the same selection and bulk actions, the same URL-synced state. There is no second component to build and no mobile-only prop tree to maintain.

What changes, and what does not

  • Each row renders as a card with a title, subtitle and the fields you mark as summary columns; the rest collapse behind a details toggle.
  • Selection, bulk actions and row expansion work exactly as they do in the table layout.
  • Pagination becomes infinite scroll, so a thumb never has to find a page control.
  • The switch is automatic by viewport, and can be forced either way with forceMobile for testing.
