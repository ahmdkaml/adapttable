React data table filters

Declare what a column filters by and the table builds the control. Text and number columns get operators — contains, equals, greater than, between — dates get ranges with relative presets like "last 30 days", and a checklist column offers the values actually present in the data, with counts. Nothing here is a bespoke filter panel: each kit renders the popover and its inputs with its own components.

What you can drive here

  • Open Filters and combine several at once — each active filter shows as a chip that removes itself when clicked.
  • Switch between the popover and a filter row under the header, which is the same state rendered in a different place.
  • Build an AND/OR tree for the conditions a single row of inputs cannot express, and nest groups inside it.
  • Watch the address bar: the whole filter state is in the URL, so a filtered view is a link you can send to someone.
  • Switch UI kit and see the same filters in that kit's controls.
