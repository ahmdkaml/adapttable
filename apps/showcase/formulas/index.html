AdaptTable demo — formula columns

Type =ROUND(budget * 0.15, 0) into the formula bar and the table gains a column computed from every row — no code, no rebuild. Text works the same way: =UPPER(team) & " · " & role joins two fields into one cell. A formula is parsed rather than evaluated as JavaScript, which is what makes it safe to carry in a link somebody sends you.

What you can drive here

  • Add a formula column, name it, and sort it — text sorts alphabetically, numbers numerically.
  • Remove a column again; the whole set lives in the URL, so a reload and a shared link both reproduce it.
  • Watch an error land in the cell that caused it — #DIV/0! for a division by zero, #NAME? for a column that is not there.
  • Add two formulas that reference each other and read #CYCLE! instead of crashing the page.
  • Switch the UI kit and the same computed columns render in Mantine, MUI, Chakra, Ant Design, Radix, Base UI, shadcn/ui or Tailwind.
