AdaptTable Feature Lab

Every shipped feature, on one table, with a toggle each. Start from a working recipe — a plain table, a filtered one, a grouped one — then tune the pieces individually and watch the configuration summary keep up. Incompatible combinations are disabled with the reason stated rather than left to fail quietly.

What you can turn on here

  • Data — the in-memory tier or a server-backed one, with the same table on top of either.
  • Filtering — a popover, a drawer, or a filter row under the header, plus the AND/OR builder.
  • Structure — flat rows, grouped rows, a tree, or a nested table inside each row; column groups; a sparkline column.
  • Editing — per cell, per row, or batched, including the boolean and multi-select editors.
  • Row features — add and delete, reorder, pin, span cells, full-width rows, per-row styling.
  • Presentation — density, motion, dark mode, and the Arabic locale with the whole layout mirrored.

One feature per page is easier to read, so most of these also have a page of their own: filtering, tree data, selection, pagination, live updates, accessibility. Back to the live demo.
