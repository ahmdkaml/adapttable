AdaptTable demo — export and print

The grouped table downloads as a real PDF from the toolbar Export button, and Print opens the browser dialog on the same view — column widths, nested groups and page breaks — because that is what the reader can actually see.

What you can drive here

  • Export PDF writes every filtered row, not just the current page.
  • The file honours group headers, column widths and page breaks.
  • Print is opt-in chrome over a host-owned handler: this page wires printTable to onPrint, and printButton is what puts a Print button in the toolbar.
