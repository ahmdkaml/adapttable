Accessible React data table

Most tables are reachable by keyboard in the sense that Tab eventually gets you through them. A grid is different: arrow keys move a single focus point one cell at a time, Home and End jump to the row's edges, and the cell that has focus says so with a visible ring rather than leaving the reader to guess.

What gets announced, and why

  • Cell moves — the column name and the value, so a screen-reader user knows where they are without re-reading the row.
  • Sorting — the column and the new direction, because the rows have just changed underneath them.
  • Filtering — how many rows remain, which is the only way to tell an empty result from a broken one.
  • Edits and exports — whether the change was accepted or rejected, and when a file is ready, since neither is visible.

The demo repeats each of these on screen as it happens, read from the same live regions a screen reader uses — so the announcements can be checked rather than taken on trust.
