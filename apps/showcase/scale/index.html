AdaptTable demo — 50,000 rows, virtualized

Fifty thousand rows in the browser at scroll speed. Only the visible window is rendered, so the DOM stays small while sorting, filtering and selection continue to operate over the whole dataset rather than the visible slice.

What you can drive here

  • Scroll continuously through 50,000 rows with a bounded DOM.
  • Sort and filter across the entire set — the result is the whole dataset reordered, not the rendered window.
  • Select all, then act on the full selection including rows never scrolled into view.
  • Virtualization applies to mobile cards too, not only to table rows.
  • Pinned columns and sticky headers survive virtualized scrolling.

Documentation: virtualization, data tiers, selection, pagination. Other demos: the main showcase, mobile cards.
