React table row selection and bulk actions

Selecting rows is half a feature — the other half is doing something with them. AdaptTable holds the selection as a set of row ids rather than a slice of the visible page, so a row ticked on page one is still ticked while page three is on screen, and a bulk action runs against everything chosen rather than everything rendered.

What you can drive here

  • Tick rows individually, or take the whole page from the header checkbox.
  • Page away and back: the selection is still there, because it was never tied to what was on screen.
  • Run a bulk action over the selection — destructive ones ask for confirmation through the kit's own dialog first.
  • Switch UI kit: the checkbox, the action bar and the confirmation are that kit's components, not a shared imitation of them.
